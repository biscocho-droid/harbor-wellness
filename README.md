# Harbor

Harbor is a calm, self-guided coping app with four paths: Depression, Panic,
Anxiety, and Rumination. Each path offers short grounding, reflection, or
behavioral steps designed to help someone through a difficult moment.

Harbor is an educational self-support tool. It does not provide diagnosis,
treatment, or emergency services and is not a substitute for professional care.

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
